# SmartClaims UX and Design System

Status: Draft v0.1 | 2026-10-14

## Roles and navigation
Member: Home, File Claim, My Claims, Documents, Messages.
Adjuster: Work Queue, Claim 360, Approvals, Exceptions.
Provider: Jobs, Calendar, Estimates, Parts.
Dealer: RFQs, Orders, Inventory, Shipments.
Admin: Tenants, Users, Rules, Audit.

## Tokens
Primary #2563EB; ink #0F172A; surface #F8FAFC; success #16A34A; warning #D97706; 8px spacing scale; 12px card radius; Inter/system font.

## Interactions
Global search, keyboard navigation, queue sorting/filtering, responsive nav, saved views, accessible dialogs, status feedback, loading/error/empty states, claim timeline and evidence viewer.

## Accessibility
WCAG 2.2 AA target, semantic landmarks, visible focus, keyboard flows, contrast and text status labels.

## AI presentation
Display recommendation evidence and confidence, reject/override option and human authorization state; never present draft AI findings as adjudicated facts.
